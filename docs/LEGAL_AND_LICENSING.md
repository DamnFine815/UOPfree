# Project origin and distribution

UOPfree is an independently developed community modification based on examining the supported OPPO UDP-203 RU-JB player environment. Its USB release packages contain the project's shell scripts and text manifests, **not** a proprietary player executable, full firmware image or device keys.

The project does not claim rights over OPPO firmware, trademarks or third-party materials and is not affiliated with OPPO Digital. External sources are listed in [References](SOURCES.md).
