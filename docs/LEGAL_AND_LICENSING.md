# Project origin and distribution

UOPfree is an independently developed community modification based on studying the OPPO UDP-203 RU-JB player environment. Its published USB packages contain its original shell scripts and text manifests, not a proprietary player executable, a complete firmware image, or device keys.

**License:** Original UOPfree code, installer/uninstaller scripts, reproducible source tools and documentation are available under the [MIT License](../LICENSE). The author explicitly permits its integration into [oppo-dv-mkv](https://github.com/fandangos/oppo-dv-mkv), including a separate On/Off setting, while retaining the MIT copyright and permission notice. Use of this code remains subject to the usual firmware-compatibility and hardware safety checks.
